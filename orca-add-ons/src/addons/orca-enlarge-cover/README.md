# Orca Enlarge Cover NDE Add-on

## Details

- Name: `orca-enlarge-cover`
- URL: `https://alliance-pcsg.github.io/nde-add-ons/orca-enlarge-cover/`
- Configuration JSON Template: [orca-enlarge-cover.json](./orca-enlarge-cover.json)
- Placement: `nde-record-image-after`
- Component Folder: [`src/app/orca-enlarge-cover`](../../app/orca-enlarge-cover)
- Component Selector: `orca-enlarge-cover`

## Description

This add-on inserts a button under cover images on brief and full records that, when clicked, opens the image at full size in a dialog.

## Configuration

Set the text of the button as "buttonText" in the configuration JSON.
